# Machine Learning Projects

This repository contains Machine Learning projects focused on data cleaning, preprocessing, classification, and model evaluation.

## Projects

### Titanic Survival Prediction
Predicting whether a passenger survived the Titanic disaster using Logistic Regression.

### Telco Customer Churn Prediction
Predicting whether a customer will churn using Logistic Regression and Naive Bayes.



## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab / Jupyter Notebook

## Skills
Data Cleaning • Data Preprocessing • Classification • Model Training • Accuracy Evaluation
